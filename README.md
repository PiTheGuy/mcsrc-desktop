The unofficial desktop app for [mcsrc.dev](https://mcsrc.dev)!

## Features
- Faster, cleaner, decompile output by utilizing real Vineflower rather than a web version
- Indexing and remapping are run on the JVM for better performance

## Development
Use `./gradlew dev` to load a locally hosted version of the server and add a button to access dev tools
